# 設備管理系統（Equipment Management System）

## 專案簡介

本專案為一套全端設備管理系統，提供設備管理、借用與歸還功能，協助管理設備使用情況，並降低人工管理成本。

本系統採用前後端分離架構，前端使用 HTML、CSS、Bootstrap 與 JavaScript 開發；後端使用 Node.js 與 Express 建立 RESTful API；資料庫使用 MySQL 儲存所有資料。

---

## 專案功能

### 一般使用者

- 使用者登入
- 查看設備列表
- 搜尋設備
- 借用設備
- 歸還設備
- 查看個人借用紀錄

### 管理員

- 新增設備
- 修改設備資訊
- 刪除設備
- 管理使用者
- 查看所有借用紀錄
